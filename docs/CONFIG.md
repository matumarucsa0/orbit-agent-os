# Configuration map

Generated by `scripts/gen_codemap.py` (do not edit; `make codemap` rewrites it).
Every field of `orbit/settings.py::Settings` as an environment variable (or `.env`
entry), its type, default and what it does; `.env.example` has the commented
template. Secrets are `SecretStr` and are never printed. The defaults shown are the
code defaults; values edited on `/settings/schedule` override some of them at run time
(`services/schedule_config.py::OverrideStore`).

## CLI commands

| Command (`uv run python -m orbit.cli ...`) | What |
|---|---|
| `hash-password` | print an argon2 hash line for .env |
| `test-push` | send a test push notification via ntfy |
| `copy-db` | copy all data from another database into an empty, migrated one |
| `smoke-test` | read-only checks of a running instance (HTTPS, API, ICS feed) |
| `usage` | Claude calls and tokens per month |
| `export` | write all data as JSON |
| `seed-demo` | fill an empty database with a fictional demo persona (no network) |
| `prompts-snapshot` | record the prompt text hashes and versions for the prompt-version test |
